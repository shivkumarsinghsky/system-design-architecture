# Changelog

All notable changes to this repository are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-10-02

### Added

- Dockerfile and docker compose service for the capacity estimator.
- Twelve reference system designs with a CI-enforced common structure.
- Capacity estimation package (`tools/capacity`) with generated tables embedded in each design.
- Fundamentals: design method, building blocks, consistency and messaging, reliability checklist.
- ADR-001 to ADR-005.
- CI: lint, tests, capacity-table drift, design structure, internal links, Mermaid rendering.
